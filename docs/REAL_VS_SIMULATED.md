# What is real, what is simulated

**This is a prototype, not an official service.**

| Area | Status | Notes |
|---|---|---|
| Authentication (JWT), RBAC, tenant isolation | **Real** | Enforced server-side on every route; tested with raw HTTP. |
| Consent broker, withdrawal, access log | **Real** | One gate for all personal-data reads; effect is immediate. |
| Hash-chained audit log + verification | **Real** | SHA-256 chain; verify endpoint; simulated-tamper proof. |
| Versioned rules engine, Digital Twin | **Real** | JSON rules, no `eval`; decisions pin the rule version. |
| Decision engine (expected cost) | **Real** | Pure function, unit-testable, numbers shown in UI. |
| Identity matching (Fellegi–Sunter) | **Real algorithm, MOCK registry** | Runs against a **synthetic** registry. |
| Document checks (blur, QR signature, cross-check) | **Real** | On **synthetic, watermarked sample cards**. Signature scheme is a mock issuer key. |
| OCR | **Real if Tesseract installed** | Otherwise skipped and reported. |
| Scam classifier | **Real model, synthetic training data** | Small dataset; honest confusion matrix at `/scam/eval`. |
| RAG | **Real retrieval (BM25), MOCK policy documents** | Policy pack is written for this demo, modelled on public BISP/PTA advice. |
| Voice | **Real** | Browser speech recognition/synthesis + pre-rendered Urdu clips. |
| NADRA / Verisys identity service | **SIMULATED** | `/mock/nadra/*`, synthetic people. |
| Raast / payments | **SIMULATED** | `/mock/raast/*`, `MOCK-` references, no money moves. |
| SMS / WhatsApp / email | **SIMULATED** | Written to the notifications table as `[MOCK SMS]`. |
| OTP for Helper Mode | **SIMULATED** | Code is returned in the demo response. |
| All people, CNICs, phone numbers, incomes | **SYNTHETIC** | Generated by `backend/app/seed.py`. |
